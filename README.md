# ❤️ Cardiovascular Disease Dataset Analysis & Prediction

## 📌 Project Overview

This project focuses on analyzing cardiovascular health data and identifying patterns associated with cardiovascular disease using Python and Machine Learning.

The project explores patient health indicators, lifestyle habits, and medical measurements to understand their relationship with cardiovascular disease.

The goal is to perform data cleaning, exploratory data analysis (EDA), data visualization, and machine learning-based classification.

## 🎯 Objectives

- Analyze cardiovascular health-related data.
- Perform data cleaning and preprocessing.
- Identify missing values, duplicates, and outliers.
- Explore relationships between health indicators.
- Visualize important patterns and correlations.
- Build machine learning models to classify cardiovascular disease.
- Evaluate model performance using appropriate metrics.

## 📂 Dataset Information

**Dataset Name:** Cardiovascular Disease Dataset

**Source:** Kaggle

**Dataset Link:** https://www.kaggle.com/datasets/sulianova/cardiovascular-disease-dataset

**Dataset Size:** 70,000 records

**Total Columns:** 13

**Target Variable:** `cardio`

## 📊 Dataset Features

| Feature | Description |
|---|---|
| id | Unique patient identifier |
| age | Patient age (in days) |
| gender | Gender category |
| height | Height in centimetres |
| weight | Weight in kilograms |
| ap_hi | Systolic blood pressure |
| ap_lo | Diastolic blood pressure |
| cholesterol | Cholesterol level category |
| gluc | Glucose level category |
| smoke | Smoking status |
| alco | Alcohol consumption status |
| active | Physical activity status |
| cardio | Cardiovascular disease indicator |

### Target Variable

- `0` – Cardiovascular disease not recorded.
- `1` – Cardiovascular disease recorded.
